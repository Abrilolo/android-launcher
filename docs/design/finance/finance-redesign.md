# Finance refinement

Preserve native Android typography, black surfaces and existing semantic colors. Today owns actionable daily availability and today's ledger, without charts. Summary owns the daily trend chart, period selection, textual type breakdown and ledger. Bank owns balances; Budget owns planning, without another allocation chart. Advanced settings owns bank-notice permission and an explicit optional daily override. Goals own target, saved amount, deadline preview and progress.

The generated settings/goal reference is a composition guide, not a screenshot of the implementation or a claim of pixel parity. Keep existing controls and accessible text; do not render the image as UI.

Pending payments now require explicit confirmation after choosing daily, fixed or monthly scope. Fixed costs can link to a planned reserve. Food still proceeds to meal registration. Large amounts suggest reviewing scope but never reclassify silently. Existing data contracts and meal links are retained.

Goal edits preserve the existing deadline unless the period changes. New deadlines use today; preview and save share the same deadline. Deletion requires confirmation. Scheduled-payment edits can be cancelled; account details expose a visible Back action.
